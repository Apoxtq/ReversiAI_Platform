# 技术栈约束（版本锁定）

---

## 🎓 英国大学毕业设计技术选型标准

**重要声明**: 技术栈选择须符合**University of Liverpool**计算机科学教育的学术标准，并为毕业设计评估提供充分的技术深度论证。

### 📜 学术技术选型原则

#### 1. 技术选择论证标准
- **教育价值**: 选择的技术须体现计算机科学核心概念
- **行业标准**: 采用学术界和工业界认可的技术栈
- **学习曲线**: 技术复杂度适合理论学习和实践应用
- **研究价值**: 支持有意义的学术研究和实验

#### 2. 版本锁定学术依据
- **稳定性论证**: 版本选择基于社区稳定性和长期支持考虑
- **兼容性分析**: 评估版本间兼容性和迁移成本
- **安全评估**: 基于学术安全研究选择安全版本
- **性能基准**: 版本选择考虑已验证的性能表现

#### 3. 约束设置的学术目的
- **简化复杂度**: 通过约束减少变量，便于学术分析
- **质量保证**: 技术约束确保工程实践的专业性
- **可重现性**: 固定技术栈保证实验结果的可重现性
- **评估公平性**: 为毕业设计评估提供标准化的技术环境

## 编译器和语言
- C++17 标准（不使用C++20特性，除非已测试兼容性）
- Visual Studio 2019+ / GCC 9+ / Clang 10+
- 必须支持C++17 filesystem和optional

## 依赖库（仅允许以下库）
- Qt 5.15+ 或 Qt 6.2+ （UI框架）
- 标准库 std::（优先使用）
- 不得使用：Boost, OpenCV等未列出的库

## 位运算优化
- 棋盘表示：uint64_t位图（参考@examples/bitboard_sample.cpp）
- 必须内联关键函数（__forceinline 或 inline）
- 使用编译器内建函数：__builtin_popcountll
- 方向掩码预计算

## 网络协议
- 使用Qt的QTcpSocket（不使用原始socket API）
- 协议格式：JSON文本协议（不使用二进制协议）
- 同步方式：Qt信号槽机制
- 连接超时：30秒

## 构建系统
- CMake 3.16+ （必须使用现代CMake）
- 支持开发生成器（Ninja/Visual Studio/Make）
- 统一输出目录结构
- 自动依赖检测

## 测试框架
- Google Test 1.10+ （单元测试）
- Qt Test （UI测试）
- 性能基准测试：Google Benchmark

## 文档工具
- Doxygen 1.9+ （API文档）
- Markdown （设计文档）
- Graphviz （架构图）

## 性能目标
- 编译时间：< 30秒 (full rebuild)
- 可执行文件大小：< 50MB
- 内存占用：< 100MB (运行时)
- AI响应时间：< 5秒 (Hard难度)

## 平台支持
- Windows 10+ (主要平台)
- Linux Ubuntu 18.04+ (兼容)
- macOS 10.15+ (兼容)
- 必须64位架构
