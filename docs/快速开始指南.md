# ReversiAI_Platform 快速开始指南

**版本**: v1.0.0  
**预计阅读时间**: 5分钟

## 5分钟快速入门

### 第一步：获取可执行文件

从GitHub Releases下载最新版本：
```bash
# 访问 https://github.com/Apoxtq/ReversiAI_Platform/releases
# 下载 ReversiAI_Platform_v1.0.0_windows_x64.zip
# 解压后运行 ReversiAI_Platform.exe
```

### 第二步：启动程序

双击运行 `ReversiAI_Platform.exe`，你将看到主菜单界面：

```
┌─────────────────────────────────────────┐
│         ReversiAI_Platform              │
│            主菜单                        │
├─────────────────────────────────────────┤
│                                          │
│    [  人机对战 (PvE)  ]                 │
│    [  本地双人 (PvP)  ]                 │
│    [  线上对战 (Network) ]              │
│    [ 棋谱回放分析 (Replay) ]            │
│    [    AI研究/基准测试    ]            │
│                                          │
└─────────────────────────────────────────┘
```

### 第三步：开始游戏

**立即开始人机对战**：
1. 点击 **"人机对战"** 按钮
2. 选择难度 **"简单"** (首次游戏推荐)
3. 选择 **"玩家先手"**
4. 点击 **"开始游戏"**

### 第四步：落子

- 轮到你的回合时，点击棋盘上的绿色高亮位置落子
- 黑棋(X)为你，白棋(O)为AI
- 夹击对方棋子即可翻转

## 编译指南（开发者）

### 环境要求

| 工具 | 版本 | 下载地址 |
|------|------|---------|
| CMake | 3.16+ | cmake.org |
| GCC/MinGW | 9+ | msys2.org |
| Qt | 6.10+ | qt.io |

### Windows编译步骤

```powershell
# 1. 克隆项目
git clone https://github.com/Apoxtq/ReversiAI_Platform.git
cd ReversiAI_Platform

# 2. 创建构建目录
mkdir build
cd build

# 3. 配置CMake
cmake .. -DBUILD_QT_GUI=ON -DCMAKE_BUILD_TYPE=Release

# 4. 编译
cmake --build . --config Release

# 5. 部署Qt依赖
windeployqt ReversiAI_Platform.exe

# 6. 运行
./ReversiAI_Platform.exe
```

### Linux编译步骤

```bash
# 1. 安装依赖
sudo apt install build-essential cmake qt6-base-dev

# 2. 克隆并编译
git clone https://github.com/Apoxtq/ReversiAI_Platform.git
cd ReversiAI_Platform
mkdir build && cd build
cmake .. -DBUILD_QT_GUI=ON -DCMAKE_BUILD_TYPE=Release
cmake --build . --config Release

# 3. 运行
./ReversiAI_Platform
```

## 游戏模式说明

### 1. 人机对战 (PvE)

与AI进行对战，可选难度：
- **简单**: 适合初学者，AI搜索深度2-3层
- **中等**: 有挑战性，AI搜索深度4-5层
- **困难**: 高水平对战，AI搜索深度6-8层

### 2. 本地双人 (PvP)

两名玩家在同一台电脑上对战，轮流落子。

### 3. 线上对战 (Network)

局域网对战功能：
1. 点击"线上对战"
2. 创建房间或加入现有房间
3. 与对手进行网络对战

### 4. 棋谱回放分析

分析学习对局：
1. 点击"棋谱回放分析"
2. 打开PGN或SGF格式的棋谱文件
3. 使用播放按钮复盘
4. 查看AI分析（热度图、搜索树）

### 5. AI研究/基准测试

运行AI性能测试：
1. 进入AI研究模式
2. 可运行AI对战、性能基准测试
3. 导出实验数据（JSON/CSV格式）

## 常见问题

### Q: 程序无法启动？

**A**: 
1. 确认已安装Visual C++ Redistributable
2. 运行 `windeployqt` 部署Qt依赖
3. 将Qt的bin目录添加到PATH

### Q: 编译报错"Qt6 not found"？

**A**: 设置Qt路径环境变量：
```powershell
$env:Qt6_ROOT = "C:/Qt/6.10.1/mingw_64"
```

### Q: 网络对战无法连接？

**A**: 
1. 确认在同一局域网
2. 检查防火墙是否阻止
3. 尝试禁用杀毒软件

### Q: AI思考时间太长？

**A**: 
1. 降低游戏难度
2. 关闭其他占用CPU的程序
3. 使用 Release 模式编译
