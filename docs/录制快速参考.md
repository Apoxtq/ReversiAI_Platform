## 功能演示顺序

### 1. 主界面 (10秒)
- 展示5个主要功能按钮
- 版本信息显示在副标题下方

### 2. 人机对战 PvE (3分钟)
1. 点击"人机对战 (PvE)"
2. 选择"Player First"（玩家先手）
3. 点击"Start"
4. 在高亮位置点击落子
5. 观察AI自动走棋和分数变化

### 3. 本地双人对战 PvP (2分钟)
1. 返回主菜单
2. 点击"本地双人 (PvP)"
3. 点击"Start"
4. 两人轮流落子
5. 演示"悔棋"功能

### 4. AI研究模式 (4分钟)
1. 返回主菜单
2. 点击"AI Research Mode"
3. 默认配置: Minimax Medium vs RandomAI
4. 点击"Start Battle"
5. 等待10局对战完成
6. 展示统计结果
7. 点击"Bitboard Benchmark"演示基准测试

### 5. 棋谱回放分析 (2分钟)
1. 返回主菜单
2. 点击"Game Replay Analysis"
3. 点击"New Game"创建演示对局
4. 使用播放控制演示回放功能

### 6. 网络对战 (可选，1分钟)
1. 返回主菜单
2. 点击"网络对战 (PvN)"
3. 展示创建/加入房间界面
4. 说明需要两台电脑在局域网内

## 常见问题快速解答

| 问题 | 解答 |
|------|------|
| 无法启动 | 确保在Release_Package目录运行 |
