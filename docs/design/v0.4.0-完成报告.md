## 🐛 修复的Bug

### Bug 1: PvP模式下白棋无法落子

**问题**: PvP模式下，白棋回合被错误地设为 `AITurn`，导致无法落子

**修复**: 修改 `GameController::switchTurn()` 的阶段判断逻辑

```cpp
// 修复前（错误）
bool isHumanTurn = (currentPlayer_ == humanColor_) && 
                   (gameMode_ == GameMode::PvE || gameMode_ == GameMode::PvP);

// 修复后（正确）
bool isHumanTurn = (gameMode_ == GameMode::PvP) || (currentPlayer_ == humanColor_);
```

### Bug 2: 棋盘坐标系统不匹配

**问题**: paintEvent 中 `board.at(i,j)` 的索引顺序与实际显示位置不符

**修复**: 修正坐标访问顺序

```cpp
// 修复前（错误）
int cellValue = board.at(i, j);  // i=水平, j=垂直
painter.drawPixmap(0 + 50 * i, 0 + 50 * j, ...);  // i=x, j=y

// 修复后（正确）
int cellValue = board.at(j, i);  // j=row(垂直), i=col(水平)
```
