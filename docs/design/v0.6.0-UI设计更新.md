## 3. 界面功能

| 功能 | 说明 |
|------|------|
| AI选择器 | 支持MinimaxAI (Easy/Medium/Hard) 和 RandomAI |
| 深度配置 | 可设置搜索深度 2-5 |
| 对局数量 | 可设置1-1000局 |
| 进度显示 | 实时显示对局进度 (QProgressBar) |
| 统计结果 | 显示胜率、平均回合数、总耗时 |
| 报告导出 | 支持导出TXT/CSV格式报告 |

## 5. AIvsAIWindow详细设计

### 5.1 类结构

```cpp
namespace Reversi {

class AIvsAIWindow : public QMainWindow {
    Q_OBJECT

public:
    explicit AIvsAIWindow(QWidget* parent = nullptr);
    ~AIvsAIWindow() override;

signals:
    void backToMenu();  // 返回主菜单信号

private slots:
    void onStartBattleClicked();   // 开始对战
    void onStopBattleClicked();    // 停止对战
    void onExportReportClicked();  // 导出报告
    void onBackClicked();          // 返回
    void updateProgress();         // 更新进度
    void onBattleCompleted(const BattleStats& stats);  // 对战完成

private:
    void setupUI();
    void setupConnections();
    void updateStatsTable();
    void clearStats();
    void setControlsEnabled(bool enabled);

    // UI组件
    QComboBox* ai1Combo_;
    QComboBox* ai2Combo_;
    QSpinBox* gamesSpinBox_;
    QProgressBar* progressBar_;
    QTableWidget* statsTable_;
    QTextEdit* resultText_;

    // 状态
    bool isRunning_;
    BattleConfig battleConfig_;
    BattleEngine* battleEngine_;

    // 统计数据
    int gamesPlayed_;
    int gamesWon1_;
    int gamesWon2_;
    int draws_;
    double avgMoves_;
};

} // namespace Reversi
```

### 5.2 对战流程

```
1. 用户选择AI1、AI2、深度、对局数
2. 点击"Start Battle"
3. 创建BattleEngine，配置参数
4. 使用QtConcurrent::run()在后台运行对战
5. 定时更新进度条
6. 对战完成后显示结果
7. 可导出报告
```
