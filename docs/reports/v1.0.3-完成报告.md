## 2. Bug 修复详情

### 2.1 悔棋功能无法完全撤销

#### 问题描述

在本地双人模式下，经过多次落子（约 10 步以上）后，悔棋功能失效：
- 界面显示 "No moves to undo"
- 棋盘无法回滚到初始状态
- 残留棋子无法清除

#### 问题分析

通过日志分析发现两个问题：

**问题 1：`undoMove()` 逻辑错误**

```cpp
// 修复前的代码（错误）
board_ = std::make_unique<Board>(*moveHistory_.back());
moveHistory_.pop_back();  // pop_back 后...
currentPlayer_ = moveHistory_.back()->getCurrentTurn();  // 获取的是再前一步的状态！
```

恢复玩家轮次时使用 `moveHistory_.back()`，但此时 `pop_back()` 已执行，获取的是**再前一步**的棋盘状态，导致玩家轮次错误。

**问题 2：历史记录数量限制过小**

```cpp
// 修复前
constexpr int MAX_UNDO_STEPS = 10;  // Reversi 最多 60 步，限制太小
```

Reversi 棋局最多约 60 步，但悔棋历史只保存 10 步，超过后旧记录被丢弃。

#### 修复方案

**`src/ui/GameController.cpp` — `undoMove()` 修改**：

```cpp
// 修复后的代码（正确）
board_ = std::make_unique<Board>(*moveHistory_.back());
moveHistory_.pop_back();
currentPlayer_ = board_->getCurrentTurn();  // 直接从恢复的棋盘获取
```

**`src/ui/GameController.cpp` — `MAX_UNDO_STEPS` 修改**：

```cpp
// 修改前
constexpr int MAX_UNDO_STEPS = 10;

// 修改后
constexpr int MAX_UNDO_STEPS = 60;  // Reversi 最多 60 步
```

## 3. UI 优化详情

### 3.1 PvEWindow 右面板布局调整

#### 调整内容

| 调整项 | 修改前 | 修改后 |
|--------|--------|--------|
| AI First/Player First | 水平排列 | 垂直排列 |
| Controls 位置 | 居中 | 往下移动 |
| 弹性空间 | `addStretch()` | `addStretch(2)` |

#### 修改文件

**`ui/pvewindow.cpp` — `setupAIConfig()`**：

```cpp
// 修改前（水平排列）
QHBoxLayout* firstMoveLayout = new QHBoxLayout();
firstMoveLayout->addWidget(aiFirstRadio_);
firstMoveLayout->addWidget(playerFirstRadio_);
firstMoveLayout->addStretch();
groupLayout->addLayout(firstMoveLayout);

// 修改后（垂直排列）
QVBoxLayout* firstMoveLayout = new QVBoxLayout();
firstMoveLayout->setSpacing(5);
firstMoveLayout->addWidget(aiFirstRadio_);
firstMoveLayout->addWidget(playerFirstRadio_);
groupLayout->addLayout(firstMoveLayout);
```

**`ui/pvewindow.cpp` — 主布局**：

```cpp
// 修改前
rightLayout_->addStretch();

// 修改后
rightLayout_->addStretch(2);  // 增加弹性空间
```
