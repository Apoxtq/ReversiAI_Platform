## 改进项1：Pass/Fail 判定显示

### 1.1 需求背景

根据 `Reversi_Proposal.md` Section 8.3，验收标准包含明确的 Pass/Fail 阈值。

**Primary Performance (AI Strength)**:
- Minimax (depth-6) ≥90% vs Random → 100 games
- MCTS (10k sims/move) ≥70% vs Minimax (depth-4) → 50 games

**Secondary Efficiency (Indicative Targets)**:
- Bitboard flip speed: ≥100 M/s
- Minimax throughput: ≥2.0 M nodes/s
- MCTS simulation rate: ≥200 K sims/s
- AI stability: 100 consecutive games, 0 crashes

### 1.2 现有问题

- 测试结果只显示数值，不显示是否达标
- `BattleStats` 结构体中没有 `passed` 字段

### 1.3 设计方案

#### 1.3.1 新增目标值定义

```cpp
// include/research/BenchmarkTargets.h
#pragma once

namespace Reversi {

/**
 * @brief 基准测试目标值定义
 *
 * 来自 Reversi_Proposal.md Section 8.3
 */
struct BenchmarkTargets {
    // ===== Primary Performance (AI Strength) =====
    static constexpr double MINIMAX6_VS_RANDOM_WINRATE = 0.90;  // ≥90%
    static constexpr double MCTS_VS_MINIMAX4_WINRATE = 0.70;    // ≥70%
    static constexpr int MINIMAX6_VS_RANDOM_GAMES = 100;         // 100 games
    static constexpr int MCTS_VS_MINIMAX4_GAMES = 50;           // 50 games

    // ===== Secondary Efficiency (Indicative Targets) =====
    static constexpr double BITBOARD_FLIP_SPEED = 100.0;        // ≥100 M/s
    static constexpr double BITBOARD_MOVE_GEN = 50.0;          // ≥50 M/s
    static constexpr double BITBOARD_LEGAL_CHECK = 100.0;      // ≥100 M/s
    static constexpr double BITBOARD_COPY = 20.0;              // ≥20 M/s

    static constexpr double MINIMAX_THROUGHPUT = 2.0;           // ≥2.0 M nodes/s
    static constexpr double MCTS_SIMULATION_RATE = 200.0;       // ≥200 K sims/s

    static constexpr int LAN_STABILITY_TOTAL = 10;             // 10/10 games
    static constexpr int AI_STABILITY_TOTAL = 100;             // 100 games

    // ===== Statistical Significance =====
    static constexpr double P_VALUE_THRESHOLD = 0.05;          // p < 0.05
};

} // namespace Reversi
```

### 4.1 需求背景

### 4.3 设计方案（改进版）

#### 4.3.1 估算模型

考虑更多参数，建立更准确的估算模型：

```cpp
// include/research/RuntimeEstimator.h
#pragma once

#include <string>
#include <sstream>
#include <iomanip>

namespace Reversi {

/**
 * @brief 运行时预估器
 */
class RuntimeEstimator {
public:
    /**
     * @brief 估算配置
     */
    struct EstimateConfig {
        int num_games;
        std::string ai1_type;     // "Minimax", "MCTS", "Random"
        std::string ai2_type;
        int depth;
        int mcts_simulations;     // MCTS 模拟次数
        int threads;
        int suite_size;           // 位置套件大小（0表示不使用）
    };

    /**
     * @brief 估算结果
     */
    struct Estimate {
        int estimated_seconds;
        int estimated_minutes;

        /**
         * @brief 获取显示字符串（纯 std::string，无 Qt 依赖）
         */
        std::string getDisplayString() const {
            std::ostringstream oss;
            if (estimated_minutes >= 60) {
                int hours = estimated_minutes / 60;
                int mins = estimated_minutes % 60;
                oss << "~" << hours << "h " << mins << "m";
            } else if (estimated_minutes > 0) {
                oss << "~" << estimated_minutes << " minutes";
            } else {
                oss << "~" << estimated_seconds << " seconds";
            }
            return oss.str();
        }
    };

    /**
     * @brief 计算预估时间
     */
    static Estimate calculate(const EstimateConfig& config);

private:
    // 历史数据统计（用于校准）
    static double getAverageGameTime(
        const std::string& ai1,
        const std::string& ai2,
        int depth,
        int mcts_sims
    );

    // 基础时间表（可校准）
    static double getBaseTime(const std::string& ai_type, int depth, int mcts_sims);
};

/**
 * @brief 简化版估算器
 *
 * 用于快速估算，不需要完整配置
 */
class SimpleRuntimeEstimator {
public:
    static int estimateSeconds(
        int num_games,
        const std::string& ai1,
        const std::string& ai2,
        int depth
    ) {
        // 基础时间（秒/局）
        double base_time = 0.5;

        if (ai1 == "Minimax" && ai2 == "Minimax") {
            // Minimax vs Minimax: 深度翻倍，时间指数增长
            base_time = 1.0 * std::pow(2.0, depth - 4);
        } else if (ai1 == "MCTS" || ai2 == "MCTS") {
            // 包含 MCTS: 较慢
            base_time = 3.0;
        } else if (ai1 == "Minimax" || ai2 == "Minimax") {
            // Minimax vs 其他: 根据深度
            base_time = 0.8 * std::pow(2.0, depth - 4);
        }

        return static_cast<int>(base_time * num_games);
    }
};

} // namespace Reversi
```

    /**
     * @brief 运行所有预设测试

    static std::vector<ValidationResult> runAll();

    static std::string generateReport(const std::vector<ValidationResult>& results);
