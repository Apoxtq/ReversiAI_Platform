```
docs/
├── README.md              ← 本文件
├── 快速开始指南.md         # 快速上手教程
├── 快速参考.md             # 命令速查表

├── code-patterns/          # 设计模式参考代码
│   └── strategy_pattern.cpp
├── reports/               # 项目报告与实验文档
└── design/               # 版本设计文档
```
