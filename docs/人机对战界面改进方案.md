# 人机对战界面改进方案

## 一、需求概述

参考 AI Watch Battle 界面的设计，为人机对战（PvE）界面添加 AI 配置选项，让玩家可以自主选择 AI 的算法、难度和下棋延迟。

## 二、设计目标

- 保持与 AI Watch Battle 相似的视觉风格和用户体验
- 信息栏放置在棋盘下方（与 Watch AI 相同结构）
- 允许玩家选择 AI 的算法类型（Minimax / MCTS / Random）
- 允许玩家选择 AI 的难度（Easy / Medium / Hard）
- 允许玩家选择搜索深度（2-6）
- 允许玩家选择 AI 下棋的延迟时间（0s / 0.5s / 1s / 2s）
- 保留现有的"AI 先手"和"玩家先手"选项

### 3.2 窗口尺寸

- 建议总宽度：850-900px（需要扩展以容纳右侧配置面板）
- 建议总高度：550-600px
- 布局比例：左侧信息+棋盘区域 55%，右侧配置面板 45%

### 3.3 区域说明

#### 3.3.1 顶部区域：棋盘 + 信息栏

- **棋盘**：480x480 像素，居中显示
- **信息栏**：位于棋盘下方，同一行显示 Turn 指示、黑棋数量、白棋数量

#### 3.3.2 右侧配置面板

分为两个分组：

**AI Configuration 分组：**
| 控件 | 类型 | 选项 | 默认值 |
|------|------|------|--------|
| AI先手/玩家先手 | QRadioButton x2 | AI先手 / 玩家先手 | 玩家先手 |
| Algorithm | QComboBox | Minimax / MCTS / Random | Minimax |
| Difficulty | QComboBox | Easy / Medium / Hard | Medium |
| Depth | QComboBox | 2 / 3 / 4 / 5 / 6 | 4 |
| Move Delay | QComboBox | 0s / 0.5s / 1s / 2s | 0.5s |

**Controls 分组：**
| 控件 | 说明 |
|------|------|
| Start | 开始游戏 |
| Pause/Resume | 暂停/继续（合并按钮） |
| New Game | 重新开始 |
| 返回菜单 | 返回主菜单 |

### 3.4 胜利公告

- **位置**：棋盘上方，居中显示
- **显示条件**：游戏结束后自动显示
- **隐藏条件**：点击 New Game 后隐藏
- **内容**："Black Wins!" / "White Wins!" / "Draw!"
- **样式**：大字体醒目标注，与 Watch AI 的 resultLabel 样式一致

## 四、功能逻辑

### 4.1 游戏开始流程

```
1. 玩家选择 AI 先手 或 玩家先手（单选）
2. 玩家选择 AI 算法类型
3. 玩家选择 AI 难度
4. 玩家选择搜索深度
5. 玩家选择延迟时间
6. 点击 Start 开始游戏
7. 系统根据选择初始化 AI 配置
8. 游戏按照 PvE 模式进行
```

### 4.2 延迟下棋实现

参考 AIWatchWindow 的 Move Delay 机制：

```cpp
// Move Delay 常量
constexpr int DELAY_0S = 0;
constexpr int DELAY_05S = 500;
constexpr int DELAY_1S = 1000;
constexpr int DELAY_2S = 2000;

// AI 回合延迟处理
void PvEWindow::onAITurn() {
    // 显示 AI 思考中...
    QTimer::singleShot(delayMs_, this, &PvEWindow::onExecuteAIMove);
}

void PvEWindow::onExecuteAIMove() {
    gameController_->requestAIMove();
}
```

### 4.3 暂停/继续按钮逻辑

```cpp
void PvEWindow::onPauseResumeClicked() {
    if (gameState_ == GameState::PLAYING) {
        gameState_ = GameState::PAUSED;
        pauseResumeButton_->setText("Resume");
        moveTimer_->stop();
    } else if (gameState_ == GameState::PAUSED) {
        gameState_ = GameState::PLAYING;
        pauseResumeButton_->setText("Pause");
        moveTimer_->start(delayMs_);
    }
}
```

## 五、与 AI Watch Battle 对比

| 特性 | AI Watch Battle | PvE 改进方案 |

| 算法选择 | 支持 | 支持 |
| 难度选择 | 支持 | 支持 |
| 深度选择 | 支持 | 支持 |
| 延迟选择 | 支持（Move Delay） | 支持（Move Delay） |
| 先手选择 | 无 | 支持（AI先手/玩家先手） |

## 六、复用代码

从 AIWatchWindow.cpp 复用的函数和模式：

1. `setupAIConfig()` - AI 配置控件的创建和布局
2. `setupControls()` - 控制按钮的创建
3. Move Delay 定时器逻辑
4. GroupBox + GridLayout 分组布局
5. ComboBox 样式设置

## 七、修改文件清单

| 文件 | 修改内容 |
|------|---------|
| `pvewindow.ui` | 扩展窗口尺寸，添加 AI 配置控件 |
| `pvewindow.cpp` | 添加 setupAIConfig()，实现延迟定时器，读取配置传递给 GameController |
| `PvEWindow.h` | 添加 AI 配置相关成员变量 |

## 八、方案优势

1. **布局清晰**：与 Watch AI 结构一致，用户容易理解
2. **功能完整**：覆盖 AI 配置的主要参数
3. **复用性强**：大量复用 AIWatchWindow 的代码实现
4. **实现难度中等**：主要工作是 UI 整合，核心逻辑改动小
