## 1. 简介

### 1.1 项目概述

ReversiAI_Platform 是一个完整的黑白棋（Othello/Reversi）AI算法研究与开发平台。该项目采用现代C++开发，实现了多种AI算法，包括Minimax和MCTS，为学术研究和算法性能比较提供了完整的工具链。

### 1.2 核心功能

| 功能模块 | 描述 | 版本 |
|---------|------|------|
| 位棋盘系统 | 高效的uint64_t位运算实现 | v0.2.0 |
| Minimax AI | Alpha-Beta剪枝搜索算法 | v0.3.0 |
| MCTS AI | 蒙特卡洛树搜索算法 | v0.3.0 |
| 本地双人对战 | PvP本地对战模式 | v0.4.0 |
| 人机对战 | PvE难度分级对战 | v0.4.0 |
| LAN网络对战 | 局域网多人对战 | v0.5.0 |
| 研究框架 | 基准测试与统计分析 | v0.6.0 |
| AI优化 | Killer Moves + History Heuristic | v0.7.0 |
| 性能测试 | Bitboard/AI性能基准测试 | v0.8.0 |
| 可视化增强 | 搜索树/热度图/棋谱回放 | v0.9.0 |

## 2. 安装与配置

### 2.1 从源码构建

#### 步骤1: 克隆仓库

```bash
git clone https://github.com/Apoxtq/ReversiAI_Platform.git
cd ReversiAI_Platform
```

#### 步骤2: 安装依赖

**Windows (使用MinGW)**

```bash
# 安装 MinGW-w64
# 下载地址: https://www.msys2.org/

# 使用MSYS2安装MinGW
pacman -S mingw-w64-x86_64-gcc
pacman -S mingw-w64-x86_64-cmake
pacman -S mingw-w64-x86_64-qt6
```

**Linux (Ubuntu)**

```bash
sudo apt update
sudo apt install build-essential cmake qt6-base-dev qt6-network-auth-dev
```

**macOS**

```bash
brew install cmake qt
```

#### 步骤3: 配置Qt路径

编辑 `CMakeLists.txt` 或设置环境变量：

```bash
# Windows PowerShell
$env:Qt6_ROOT = "C:/Qt/6.10.1/mingw_64"

# Linux/macOS
export Qt6_ROOT=/path/to/qt6
```

#### 步骤4: 编译项目

```bash
# 创建构建目录
mkdir build
cd build

# 配置CMake (启用GUI)
cmake .. -DBUILD_QT_GUI=ON -DCMAKE_BUILD_TYPE=Release

# 编译
cmake --build . --config Release

# Windows: 部署Qt依赖
windeployqt ReversiAI_Platform.exe
```

### 2.2 CMake构建选项

| 选项 | 默认值 | 描述 |
|------|--------|------|
| `BUILD_QT_GUI` | OFF | 构建Qt GUI应用程序 |
| `BUILD_TESTS` | ON | 构建测试可执行文件 |
| `COVERAGE` | OFF | 启用代码覆盖率分析 |
| `PERFORMANCE_TESTING` | OFF | 启用性能测试功能 |

### 2.3 环境变量

```bash
# Qt根目录
export Qt6_ROOT=/path/to/Qt/6.10.1/mingw_64

# 可选: CMake前缀路径
export CMAKE_PREFIX_PATH=$Qt6_ROOT
```

### 4.1 棋盘操作

| 操作 | 说明 | 快捷键 |
|------|------|--------|
| 落子 | 左键点击空位 | - |
| 悔棋 | 撤销上一步 | Ctrl+Z |

### 4.2 AI难度级别

| 级别 | 搜索深度 | 预估思考时间 |
|------|---------|-------------|
| 简单 (Easy) | 2-3层 | < 1秒 |
| 中等 (Medium) | 4-5层 | 1-3秒 |
| 困难 (Hard) | 6-8层 | 3-10秒 |

### 4.3 游戏规则

黑白棋规则：
- 黑棋先行
- 落子必须能夹击对方棋子
- 夹击的对方棋子全部翻转为己方
- 无合法落子时需Pass
- 双方都无合法落子时游戏结束
- 棋子多者获胜

## 5. AI算法研究

### 5.1 研究框架概述

项目提供了完整的AI算法研究工具，包括：

- **基准测试工具**: 性能测试与数据收集
- **对战引擎**: AI算法对比测试
- **统计分析**: 显著性检验与置信区间

### 5.2 AI算法实现

#### Minimax算法

基于Alpha-Beta剪枝的极小化极大算法：

```
MinimaxSearch(board, depth, alpha, beta, maximizingPlayer)
    if depth == 0 or terminalNode(board)
        return evaluate(board)
    
    if maximizingPlayer
        maxEval = -∞
        for each move in getValidMoves(board)
            eval = MinimaxSearch(board, depth-1, alpha, beta, false)
            maxEval = max(maxEval, eval)
            alpha = max(alpha, eval)
            if beta <= alpha
                break  // Beta剪枝
        return maxEval
    else
        minEval = +∞
        for each move in getValidMoves(board)
            eval = MinimaxSearch(board, depth-1, alpha, beta, true)
            minEval = min(minEval, eval)
            beta = min(beta, eval)
            if beta <= alpha
                break  // Alpha剪枝
        return minEval
```

#### MCTS算法

蒙特卡洛树搜索算法：

```
MCTSSearch(board, timeLimit)
    root = createNode(board)
    
    while elapsedTime() < timeLimit
        node = select(root)
        if not node.isFullyExpanded()
            node = expand(node)
        result = simulate(node)
        backpropagate(node, result)
    
    return root.bestChild()
```

## 9. 故障排除

### 9.1 编译问题

#### 问题: Qt6未找到

**解决方案**:
```bash
# 设置Qt路径
export Qt6_ROOT=/path/to/Qt/6.10.1/mingw_64
cmake .. -DBUILD_QT_GUI=ON -DQt6_ROOT=/path/to/Qt/6.10.1/mingw_64
```

#### 问题: MinGW编译错误

**解决方案**:
```bash
# 确保使用正确的MinGW版本
pacman -S mingw-w64-x86_64-gcc
pacman -S mingw-w64-x86_64-qt6
```

### 9.2 运行问题

#### 问题: 程序启动后无界面

**解决方案**:
```bash
# Windows: 运行windeployqt部署Qt依赖
windeployqt ReversiAI_Platform.exe

# 检查Qt DLL路径
export PATH=$Qt6_ROOT/bin:$PATH
```

#### 问题: 网络对战无法连接

**解决方案**:
1. 检查防火墙设置
2. 确认在同一局域网内
3. 检查端口是否被占用

### 9.3 性能问题

#### 问题: AI思考时间过长

**解决方案**:
1. 降低AI难度设置
2. 减少搜索深度
3. 关闭部分优化功能以节省内存
