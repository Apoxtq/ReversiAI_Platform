## 1. 概述

### 1.1 背景

根据项目设计文档 `Reversi_Proposal.md`，主界面应有 5 个按钮，其中 **AI vs AI** 和 **AI Research Mode** 目前功能重复。本设计旨在：

1. **重组主菜单**：移除重复的 AI Research Mode 按钮
2. **增加选择界面**：点击 AI vs AI 后显示选择界面
3. **新增观看模式**：实现 AI 单一对战观看功能

### 1.2 功能定位

| 模式 | 功能 | 目标用户 |
|------|------|---------|
| **AI Research Mode** | 批量对战、统计分析、导出报告 | 研究人员、需要对比AI性能 |
| **观看单一对战** | 单局对战观察、延迟控制、实时观看 | 观赏AI对战、学习AI策略 |

### 1.3 设计目标

- 界面风格与现有 NetworkGameWindow 保持一致
- 提供流畅的观看体验
- 支持多种 AI 组合对战
- MVP 版本不含撤销/回放功能

## 4. 功能设计

### 4.1 游戏流程

```
1. 用户选择 AI 配置 (黑方、白方、延迟)
2. 点击 [Start]
3. 游戏开始自动播放
   ├── 黑方 AI 计算
   ├── 延迟等待 (如设置为1秒)
   ├── 落子并更新棋盘
   ├── 白方 AI 计算
   ├── 延迟等待
   └── 重复直到游戏结束
4. 游戏结束
   ├── 显示结果
   ├── [Start] 按钮变为 [New Game]
   └── 可选择重开或返回
```

### 4.2 暂停/继续逻辑

```
状态机:
┌─────────┐
│ IDLE    │ ← 游戏未开始
└────┬────┘
     │ Start
     ↓
┌─────────┐
│ PLAYING │ ← 游戏进行中
└────┬────┘
     │ Pause          │ Resume
     ↓                 │
┌─────────┐            │
│ PAUSED  │────────────┘
└────┬────┘
     │ New Game / Start
     ↓
┌─────────┐
│  IDLE   │
└─────────┘
```

### 4.3 延迟实现

使用 `QTimer::singleShot` 实现每步延迟：

```cpp
void AIWatchWindow::playNextMove() {
    if (isPaused_) return;

    // AI 计算并落子
    Move move = ai_->findBestMove(board_, limits_);
    board_.makeMove(move);
    updateBoardDisplay();

    // 检查游戏是否结束
    if (isGameOver()) {
        showGameResult();
        return;
    }

    // 延迟后执行下一步
    QTimer::singleShot(moveDelayMs_, this, &AIWatchWindow::playNextMove);
}
```

### 4.4 AI 配置数据结构

```cpp
struct AIConfig {
    enum class Type { MINIMAX, MCTS, RANDOM };
    Type type;
    Difficulty difficulty = Difficulty::MEDIUM;
    int depth = 4;
};

// 判断是否为 Random AI
bool isRandom(const AIConfig& config) {
    return config.type == AIConfig::Type::RANDOM;
}

// 判断是否为 MCTS AI
bool isMCTS(const AIConfig& config) {
    return config.type == AIConfig::Type::MCTS;
}
```

### 4.5 AI 创建工厂

```cpp
std::unique_ptr<AIStrategy> createAIFromConfig(const AIConfig& config) {
    switch (config.type) {
        case AIConfig::Type::RANDOM:
            return AIStrategyFactory::createRandomAI();
        case AIConfig::Type::MCTS:
            return AIStrategyFactory::createMCTSAI(config.difficulty);
        case AIConfig::Type::MINIMAX:
            auto ai = AIStrategyFactory::createMinimaxAI(config.difficulty);
            // 设置深度
            return ai;
    }
}
```

## 7. 错误处理

### 7.1 无合法移动

当某方没有合法移动时：
1. 自动跳过该回合
2. 显示提示 "No valid moves, passing..."
3. 继续执行另一方的回合

### 7.2 AI 计算超时

- 设置合理的超时限制 (10秒)
- 超时后使用当前最佳移动
- 记录警告日志

### 7.3 游戏异常终止

- 点击返回按钮时检查游戏状态
- 如果游戏进行中，弹出确认对话框
- 确认后清理资源并返回
