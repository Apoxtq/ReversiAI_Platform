## 🚀 使用指南

### 编译和运行

```bash
# 1. 进入项目目录
cd ReversiAI_Platform

# 2. 创建构建目录
mkdir build && cd build

# 3. 配置CMake
cmake .. -DBUILD_QT_GUI=ON -DCMAKE_BUILD_TYPE=Release

# 4. 构建项目
cmake --build . --config Release

# 5. 部署Qt依赖
windeployqt ReversiAI_Platform.exe

# 6. 运行程序
./ReversiAI_Platform
```

### 测试流程

1. **启动程序** - 显示主菜单
2. **点击"线上对战"** - 进入网络大厅
3. **创建房间** - 输入房间名和玩家名
4. **另一台机器** - 刷新列表，加入房间
5. **开始对战** - 双人网络对战
