## 1. 版本概述

v1.0.2 是对网络对战模块的紧急 Bug 修复版本，主要解决了网络对战窗口关闭时的多次崩溃问题，并优化了返回主界面的导航逻辑。该版本确保了网络游戏结束后正确返回，提升了用户体验和程序稳定性。

### 核心目标

```
✅ 修复网络关闭崩溃
   ├── 修复 closeEvent 递归调用崩溃
   ├── 修复析构函数双重 stopHosting()
   └── 修复 clientSocket_ 断连信号连锁触发

✅ 优化导航逻辑
   ├── 返回按钮直接回到主界面（非网络大厅）
   └── 防止多次触发 disconnectFromGame()

✅ 文档与版本更新
   ├── 版本号更新 v1.0.1 → v1.0.2
   └── CHANGELOG.md 更新
```

## 2. 已修复 Bug 清单

### 2.1 closeEvent 递归调用崩溃

| 项目 | 内容 |
|------|------|
| **文件** | `src/ui/networkgamewindow.cpp` |
| **问题** | `onBackToMenuClicked` 调用 `emit backToMenu()` → menuwindow lambda 调用 `gameWindow->close()` → 触发 `closeEvent` → 执行 `disconnectFromGame()` → `closeEvent` 结束后 lambda 继续执行 `gameWindow->close()` **再次触发 closeEvent** → 崩溃 |
| **修复** | 在 `onBackToMenuClicked` 中直接设置 `isClosing_ = true`，不依赖信号链。`closeEvent` 中增加 `isClosing_` 递归保护检查 |
| **状态** | ✅ 已修复 |

### 2.2 析构函数双重调用 stopHosting()

| 项目 | 内容 |
|------|------|
| **文件** | `src/ui/networkgamewindow.cpp` |
| **问题** | `~NetworkGameWindow()` 中 `networkHost_->stopHosting()` 在 `isClosing_` 检查**之前**就被调用，导致 `onBackToMenuClicked` 已调用后析构再次调用，产生双重 `stopHosting()` |
| **修复** | 将 `isClosing_` 检查提前，当窗口已处于关闭流程时，析构函数只执行 `deleteLater()` 安全删除对象，跳过所有网络清理 |
| **状态** | ✅ 已修复 |

### 2.3 clientSocket_ 断连信号连锁触发

| 项目 | 内容 |
|------|------|
| **文件** | `network/src/networkclient.cpp` |
| **问题** | `NetworkHost::stopHosting()` 中 `clientSocket_->close()` 触发 `disconnected` 信号 → `onClientDisconnected()` 被调用 → 在 `clientSocket_` 还未被设为 `nullptr` 时已被 `deleteLater()`，后续再次访问导致崩溃 |
| **修复** | 在 `close()` 前先调用 `disconnect()` 断开所有信号，防止 `disconnected` 信号触发 `onClientDisconnected` |
| **状态** | ✅ 已修复 |

### 2.4 导航路径优化

| 项目 | 内容 |
|------|------|
| **文件** | `ui/menuwindow.cpp` |
| **问题** | 点击返回按钮回到网络大厅（`lobbyWindow`），大厅仍然保持之前的房间状态 |
| **修复** | 修改两处 `backToMenu` lambda：返回时同时关闭 `lobbyWindow`，直接显示主界面 `this->show()` |
| **状态** | ✅ 已修复 |

## 3. 代码修改详情

### 3.1 NetworkGameWindow 关闭流程修复

**`src/ui/networkgamewindow.cpp` — `onBackToMenuClicked`**：

```cpp
void NetworkGameWindow::onBackToMenuClicked()
{
    isClosing_ = true;                  // ← 第一时间设置，防止递归
    disconnectFromGame();               // ← 只调用一次网络清理
    emit backToMenu();                  // ← 通知父窗口显示 lobby
    close();                            // ← 触发 closeEvent（isClosing_ 已为 true）
}
```

**`src/ui/networkgamewindow.cpp` — `closeEvent`**：

```cpp
void NetworkGameWindow::closeEvent(QCloseEvent* event)
{
    if (isClosing_) {                   // ← 递归保护
        event->accept();
        return;
    }
    isClosing_ = true;
    disconnectFromGame();               // ← 仅通过 X 按钮关闭时调用
    event->accept();
}
```

**`src/ui/networkgamewindow.cpp` — 析构函数**：

```cpp
NetworkGameWindow::~NetworkGameWindow()
{
    if (isClosing_) {
        // 清理已在 closeEvent/onBackToMenuClicked 中完成，只需安全删除对象
        if (discovery_) {
            discovery_->stopBroadcasting();
            discovery_->deleteLater();
        }
        if (networkHost_) {
            networkHost_->deleteLater();
        }
        return;                         // ← 防止双重 stopHosting()
    }
    disconnectFromGame();
    // ...
}
```

### 3.2 NetworkHost 断连信号修复

**`network/src/networkclient.cpp` — `stopHosting`**：

```cpp
void NetworkHost::stopHosting()
{
    if (server_) {
        server_->close();
    }
    if (clientSocket_) {
        clientSocket_->disconnect();    // ← 先断开所有信号
        clientSocket_->close();         // ← 再关闭连接
        clientSocket_->deleteLater();
        clientSocket_ = nullptr;
    }
    state_ = ConnectionState::Disconnected;
}
```

### 3.3 menuwindow 返回路径修改

**`ui/menuwindow.cpp` — 两处 lambda**（加入游戏 / 创建游戏）：

```cpp
connect(gameWindow, &NetworkGameWindow::backToMenu, this,
    [this, gameWindow, lobbyWindow]() {
        gameWindow->close();
        lobbyWindow->close();            // ← 新增：关闭大厅
        this->show();                   // ← 直接回到主界面
    });
```
