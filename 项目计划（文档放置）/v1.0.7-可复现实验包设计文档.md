## 四、统计文档设计

### 4.1 统计检验方法

#### 4.1.1 Wilcoxon Signed-Rank Test

Wilcoxon signed-rank test 是一种非参数配对检验，用于比较两个相关样本的中位数差异。

**适用场景**：
- 比较两个算法的胜率差异
- 样本不服从正态分布
- 配对观察（如同一位置的两种算法对比）

**假设**：
- H0: 两个算法胜率无显著差异
- H1: 两个算法胜率存在显著差异

**检验标准**：
- p < 0.05 → 拒绝 H0，存在显著差异

#### 4.1.2 95% 置信区间

置信区间表示真实胜率以 95% 概率落在的区间范围。

**计算公式**：
```
CI = p ± 1.96 * sqrt(p * (1 - p) / n)
```

其中：
- p = 样本胜率
- n = 样本量
- 1.96 = 95% 置信水平对应的 z 值

### 4.3 统计脚本设计

```python
# statistical_analysis.py
import numpy as np
from scipy import stats

def wilcoxon_signed_rank_test(data1, data2):
    """
    执行 Wilcoxon signed-rank 检验
    data1: 算法1 的胜率数据 (配对)
    data2: 算法2 的胜率数据 (配对)
    """
    # 计算差异
    diff = np.array(data1) - np.array(data2)
    
    # 移除零差异
    diff = diff[diff != 0]
    
    # 计算统计量和 p 值
    statistic, p_value = stats.wilcoxon(diff)
    
    return statistic, p_value

def confidence_interval(p, n, confidence=0.95):
    """
    计算胜率的置信区间
    p: 样本胜率
    n: 样本量
    """
    z = stats.norm.ppf((1 + confidence) / 2)
    margin = z * np.sqrt(p * (1 - p) / n)
    return p - margin, p + margin
```
